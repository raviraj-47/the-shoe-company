# 👟 The Shoe Company – Tailwind CSS Landing Page

A fully responsive landing page built using **HTML, Tailwind CSS, and JavaScript**.

This is my first project using **Tailwind CSS**, created to practice utility-first styling, responsive layouts, positioning, and mobile navigation.

## 📱 Responsive Design

Built using Tailwind’s responsive breakpoints:

- `md:` → Tablet screens
- `lg:` → Large screens

Layout switches from:

flex-col → flex-row

Container widths controlled using:

max-w-\*
